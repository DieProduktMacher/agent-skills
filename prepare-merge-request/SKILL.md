# Prepare Merge Request

## Senior code review

Analyze the staged/changed code and answer the following:

> I am about to submit my changes as a PR. Review it like a senior software engineer would:
>
> - What's going to get questioned in review?
> - What's the weakest part of this implementation?
> - What should I refactor before pushing?
> - Where do we introduce technical debt?
>
> Additionally take the cursor rules, the definitions in the README.md, and overall best practices into account.

Return the review results directly to the user as structured feedback.
